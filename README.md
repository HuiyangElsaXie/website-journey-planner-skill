## English
A personal-use skill for website information architecture, navigation and user journeys. Continuously updated as it is used; this is a usable first version, not a measured performance case study.

### Use
Open SKILL.md in your AI assistant, or place this folder in a skill directory supported by your own assistant. Ask: “Keep my supplied page URLs and plan two enquiry journeys for first-time workshop visitors. Return a page tree, page-role table, navigation labels, CTA destinations and unresolved journey checks; do not change the site.” Supply the business/product, target audience, primary goal, lifecycle stage, source pages or pasted content, and practical constraints. Existing relevant context may be reused when access and purpose are permitted; the report records where each fact came from. Missing information is marked, and only blocking questions are asked.

### Planning flow
1. **You** supply the site goal, audience, known pages/links and constraints, distinguishing existing inventory from ideas.
2. **AI** maps page roles, navigation and journeys; unprovided steps/buttons stay unknown or explicitly proposed.
3. **You** resolve intended routes and audience priorities, and judge proposed pages, CTA destinations and URL-change trade-offs.
4. **AI** hands back the page tree, role/journey tables, assumptions and verification plan for review; implementation remains a separate decision.

### 使用方式
在 AI 助手中读取 SKILL.md，或将此文件夹放入助手支持的技能目录。示例请求：“保留我提供的页面 URL，为首次了解工作坊的访客规划两条咨询旅程。交付页面树、页面职责、导航标签、CTA 去向和待核实环节，不修改网站。”提供业务或产品、目标受众、主要目标、业务阶段、页面来源或粘贴内容，以及实际约束。允许复用有权限且与任务相关的已有上下文，并记录事实来源；缺失信息明确标注，只追问影响交付的关键问题。

### 规划流程
1. **你**提供网站目标、受众、已知页面与链接及约束，区分现状和构想。
2. **AI**规划页面职责、导航和旅程；未知步骤、按钮与拟议内容分别标注。
3. **你**确认实际路线与受众优先级，判断页面、CTA 和 URL 变更取舍。
4. **AI**交付页面树、职责与旅程表、假设及核验计划供审阅；网站实施另行决定。
